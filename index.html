Plastic packaging can be confusing. A number inside the triangle tells you the resin type—not whether your local recycling service accepts it.

RecycleRight helps you look up five common resin codes and find a map search for recycling options in an area you choose. Always check local rules before you recycle.

How it works

Three small steps to make a more informed choice.

01 ⌕

Find the resin code

Look for the number in the triangle on your plastic item. A photo can help you inspect it, but it is not automatically recognised.

02 ♻

Learn what it means

Select the matching code to see common uses and general recycling guidance from reliable sources.

03 ⌖

Check local options

Search a real map for collection options near an area you choose, then confirm acceptance with the centre.
